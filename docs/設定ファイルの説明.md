# 設定ファイルの説明（コメントを書けないファイル）

このファイルは、JSON の形のファイルの「1行ずつの意味」を書いたファイルです。
JSON には `//` のコメントを書くとこわれてしまうので、説明はここにまとめています。

---

## manifest.webmanifest（ホーム画面に追加した時の設定）

| 行 | 意味 |
|---|---|
| `"_comment"` | このファイルの説明（ブラウザは読まない） |
| `"name": "AIシフト"` | アプリの名前 |
| `"short_name": "AIシフト"` | ホーム画面のアイコンの下に出る短い名前 |
| `"start_url": "./"` | アイコンを押した時に最初に開くページ |
| `"scope": "./"` | このアプリとして開くページのはんい |
| `"display": "standalone"` | アドレスバーなしで、ふつうのアプリのように開く |
| `"background_color": "#F4EEE6"` | 開く時の一瞬の背景の色（うすいベージュ） |
| `"theme_color": "#2B211A"` | 上のバーの色（こげ茶） |
| `"lang": "ja"` | 日本語のアプリ |
| `"icons"` | アイコンの一覧 |
| `icons/icon-192.png`（192x192） | 小さいアイコン（Android のホーム画面など） |
| `icons/icon-512.png`（512x512） | 大きいアイコン（開く時の画面など） |
| `"purpose": "maskable"` | Android が丸や四角に切り抜いてよいアイコン |

※ iPhone は `index.html` の `apple-touch-icon` などを見ます。

## package.json（テストの道具の設定）

| 行 | 意味 |
|---|---|
| `"name": "shift-app"` | このプロジェクトの名前 |
| `"private": true` | npm に公開しない（まちがって公開しないように） |
| `"description"` | 説明。アプリ本体は npm なしで動く |
| `"type": "module"` | `.js` を新しい書き方（import / export）で読む |
| `"scripts"` | 短い命令の一覧 |
| `"test": "node --test tests/*.test.mjs"` | `npm test` で全部のテストを動かす |
| `"site": "sh tools/make-site.sh"` | `npm run site` で公開用の dist フォルダを作る |
| `"devDependencies"` | テストの時だけ使う道具 |
| `"@electric-sql/pglite": "0.2.17"` | パソコンの中で動く小さいデータベース（Supabase のテスト用） |

---

## package-lock.json

`npm install` が自動で作るファイルです。入れた道具の「正確な版」を記録して、
だれのパソコンでも同じ版が入るようにします。**手で書きかえない**でください。
